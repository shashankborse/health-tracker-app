# Project context

This is a personal health/workout/nutrition tracker. The full spec — problem
statement, data model, all requirements, and the phased build order — lives
in `SPEC.md` at the repo root. Read it before starting any feature work, and
build in the order laid out under "Timeline / Phasing" (Phase 1, this
skeleton, is done: password gate, Supabase client helpers, keep-alive cron).
Appendix A has the seed workout content; Appendix B has the account-setup
and deployment checklist.
